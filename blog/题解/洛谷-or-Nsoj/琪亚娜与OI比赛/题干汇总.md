## T1 琪亚娜与赤鸢

## 题目描述

"老古董，看看你干的好事！"

符华面无表情：“我又怎么了。”

“赤鸢！你的那只赤鸢跑了！”识之律者指着山下的方向，声音拔高了八度，“那是你的鸟！你的！你作为主人能不能上点心？它就这么扑棱着翅膀飞走了，你居然还在这儿站着？”

符华沉默了两秒：“……赤鸢本就是自由的。”

“自由个鬼！”识之律者差点跳起来，“你当年养它的时候可不是这么说的！‘赤鸢是我唯一的伙伴’——这话是谁说的？啊？现在它跑了你跟我说自由？”

刚好琪亚娜路过太虚山，本着~~添乱~~帮忙的理念打算帮班长把赤鸢抓回来。

.....(激烈的抓捕中)

因为养~~鸡~~赤鸢的围栏已烂了，所以她们不得不把赤鸢临时塞在一个房间中。

因为小识对于赤鸢的逃跑十分生气，所以在每只赤鸢放进房间后会狠狠的打一下这只赤鸢把它打扁。

房间的大小可能不够挤下所有的赤鸢，但是她们想尽可能的放更多的赤鸢进去。

但是赤鸢实在太多了，一时半会不知道放那些赤鸢进去。

于是这个众人就落到了身为舰长兼 Oier 的你身上。

~~至于放不进去的赤鸢，就送给琪亚娜回去养吧(不能贪污哦)。~~

## 输入格式

输入包括 $3$ 行。

输入的第一行包含 $N$ 和 $V$ ，表示跑掉的赤鸢数量和房间的大小。

接下来的 $1$ 行包括 $N$ 个整数，表示每只赤鸢原来的大小 $A_i$。

接下来的 $1$ 行包括 $N$ 个整数，表示每只赤鸢被打后的大小 $B_i$。

## 输出格式

输出包括 $2$ 行。

第一行包括一个整数 $K$，表示能放进去的最大赤鸢数量。

第二行包括 $N$ 个 1/0，表示第 $i$ 只赤鸢选/不选放入房间，输出满足条件的任意一组解即可。

## 输入输出样例 #1

### 输入 #1

```
4 10
6 5 4 7
2 3 2 4
```

### 输出 #1

```
3
1 1 1 0
```

选择第 $1,2,3$ 只赤鸢，依次放入并打扁后，占用空间分别为 $2,5,7$ 可以全部放入房间。

## 输入输出样例 #2

### 输入 #2

```
5 12
8 7 5 4 6
3 5 2 2 4
```

### 输出 #2

```
3
1 0 1 1 0
```

选择第 $4,3,1$ 只赤鸢，依次放入并打扁后，占用空间分别为 $2,4,7$ 可以全部放入房间。

## 说明/提示

$1 \le N \le 2 \times 10^5,1 \le K \le 2 \times 10^{18},1 \le B_i \le A_i \le 2 \times 10^{15}$。

对于 $10\%$ 的测试点，满足 $1 \le N \le 20$。

对于 $30\%$ 的测试点，满足 $1 \le N \le 2 \times 10^3$。

对于其中 $5\%$ 的测试点，额外满足性质 $A_i=B_i$。

对于 $60\%$ 的测试点，满足 $1 \le N \le 2 \times 10^5$。

小识：造数据的就是个废物，怎么一堆错误解法能骗过去。

## T2 琪亚娜与虚数之海

## 题目描述

虚数之海开花了！沉没在海底的世界泡残骸上开出了一朵朵由数据构成的小花。

“布洛妮娅，你说这花是什么样子的啊，我还没听说过虚数之海有花呢！“

“笨蛋琪亚娜，你已经在我耳边说了一整路了，你这种人只适合自己走——重装小兔0019c，变形”

“欸，等等我啊!!!......不对，这里怎么走啊！！！”

收到希儿的邀请，琪亚娜和布洛妮娅一起踏上了去虚数之海赏花的旅途。

但是因为琪亚娜太~~话唠~~可爱布洛妮娅自己骑着重装小兔先行离开了，只剩下琪亚娜这个路痴和一张对她没什么用的地图。

凭借~~金鱼~~惊人的记忆力琪亚娜回忆起了虚数之海的一~~个~~些规则。

首先，虚数之海由一些世界泡残骸构成，这些世界泡残骸之间通过蚀洞连接，但是蚀洞是单向的。

然后......除了她现在在编号为 $1$ 的世界泡以外，她就不知道任何信息了。

现在琪亚娜想看到尽可能多的花，但是她不走丢就已经是万幸了，你可以根据地图帮助她吗？

## 输入格式

输入的第一行包含 $N$ 和 $M$ ，表示世界泡残骸的数量和蚀洞的数量。

接下来的 $1$ 行包括 $N$ 个正整数 $W_i$，表示第 $i$ 个世界泡残骸上长出的花的数量。

接下来 $M$ 行每行包括两个整数 $u,v$，表示第 $u$ 个世界泡残骸到第 $v$ 个世界泡残骸有一个蚀洞。

## 输出格式

输出只包含一个整数，表示能看到的最多花的数量。

你不需要在意她最后到了哪个点上，因为她大可直接穿过虚数之海回月球。

## 输入输出样例 #1

### 输入 #1

```
5 6
3 2 5 4 6
1 2
1 3
2 4
3 4
3 5
4 5
```

### 输出 #1

```
18
```

## 输入输出样例 #2

### 输入 #2

```
6 5
10 1 7 20 3 100
1 2
1 3
3 4
2 5
5 6
```

### 输出 #2

```

```

## 说明/提示

$1 \le N 1 \times \le 10^5,1 \le M \le 1 \times 10^6,1 \le W_i \le 1e9$。

对于 $10\%$ 的测试点，满足性质 $M=N-1$。

对于 $10\%$ 的测试点，满足性质 $N=M$。

保证从第 $1$ 个世界泡残骸可以到达任意一个世界泡残骸。

## T3 琪亚娜与小蛋糕

## 题目描述

“真好吃啊，谢谢芽衣！”

吃着芽衣做的小蛋糕，琪亚娜满心欢喜，但是她没主要到芽衣的眼神里除了宠溺，还有一抹不一样的感情.....

“琪亚娜，吃饱了吗？”

“唔——吃饱了！”

刚刚咽下最后一块蛋糕的琪亚娜转头，恰好对上芽衣的眼神——炽热而渴望。

意识到大事不妙，琪亚娜起身边跑，可是——咕唔，吃太多了，好像跑不动了。

因为吃的太快，所以饱腹感的计算要延后，具体参照以下规则：

吃小蛋糕的时候由于琪亚娜太贪嘴，所以她想尽量吃到美味值总和最大蛋糕。

由于芽衣的手艺超群，所以每次口中残余的上一个蛋糕的甜蜜会增添的当前吃的蛋糕的风味，使总美味值加上上个蛋糕甜蜜值和当前蛋糕美味值的积(如果是吃的第一个蛋糕则只加上当前蛋糕的美味值)。

而神奇的是，对于琪亚娜来说到了第 $i$ 座山时她的饱腹感就等于吃第 $i$ 个蛋糕能够得到的最大美味值总和。

爬山的时候琪亚娜每次需要花两座山的饱腹感的差的平方的时间，最后爬到第 $i$ 座山时就可以免于上床之苦了。

为了不被芽衣追上，琪亚娜需要尽快跑到月球基地躲避(~~防止被扣烂~~)。

~~所以小蛋糕到底指的是什么呢?~~

## 输入格式

输入包括 $3$ 行。

第一行包括 $N$，表示蛋糕和山的个数。

第二行包括 $N$ 个整数 $A_i$，表示第 $i$ 个蛋糕的美味值。

第二行包括 $N$ 个整数 $B_i$，表示第 $i$ 个蛋糕的甜蜜值。

因为芽衣本来就想要琪亚娜多吃蛋糕，所以美味值和甜蜜值是递增的。

## 输出格式

输出包括 $2$ 行。

第一行包括 $1$ 个整数，表示吃第 $N$ 个蛋糕能得到的最大美味值总和。

第二行包括 $1$ 个整数，表示到达第 $N$ 座山时的最小时间。

如果你输出的第一行正确可以得到 $30\%$的分数。

## 输入输出样例 #1

### 输入 #1

```
6
1 3 5 7 9 11
```

### 输出 #1

```
216
15229
```

## 说明/提示

$1 \le N \le 2 \times 10^5,1 \le A_i,B_i \le 5 \times 10^6$。

对于 $20\%$ 的测试点，满足性质 $1 \le N \le 1 \times 10^3$。

对于 $10\%$ 的测试点，满足所有的 $A_i$ 全部相等。

芽衣：最后的答案都要开 $int128$ 了，琪亚娜是肯定跑不掉的。

```cpp
//int128 的读入
inline __int128 read() 
{
    __int128 w=0;
    char ch=getchar();
    while( isdigit( ch ) )
    {
        w=w*10+ch-'0';
        ch=getchar();
    }
    return w;
}

inline void print( __int128 num )
{
    if( num > 9 ) print( num/10 );
    putchar( num%10+'0' );
}

//比较int128乘积用, a*b <= c*d
#define QAQ return  
#define intt __int128
#define ull unsigned long long
#define uintt unsigned __int128

inline void mul128( uintt a,uintt b,uintt &hi,uintt &lo )
{
    ull al=( ull )a, ah=( ull )( a>>64 );
    ull bl=( ull )b, bh=( ull )( b>>64 );
    uintt p00=( uintt )al*bl;
    uintt p01=( uintt )al*bh;
    uintt p10=( uintt )ah*bl;
    uintt p11=( uintt )ah*bh;
    uintt mid=( p00>>64 )+( ull )p01+( ull )p10;
    lo=( p00&( ( ( uintt )1<<64 )-1 ) )|( mid<<64 );
    hi=p11+( p01>>64 )+( p10>>64 )+( mid>>64 );
}

inline bool mul_leq( intt a,intt b,intt c,intt d )
{
    int s1=( a<0 )^( b<0 );
    int s2=( c<0 )^( d<0 );
    if( s1 != s2 ) QAQ s1 > s2;
    uintt ua=( a < 0 ? ( uintt )-( a+1 )+1 : ( uintt )a );
    uintt ub=( b < 0 ? ( uintt )-( b+1 )+1 : ( uintt )b );
    uintt uc=( c < 0 ? ( uintt )-( c+1 )+1 : ( uintt )c );
    uintt ud=( d < 0 ? ( uintt )-( d+1 )+1 : ( uintt )d );
    uintt hi1,lo1,hi2,lo2;
    mul128( ua,ub,hi1,lo1 );
    mul128( uc,ud,hi2,lo2 );
    bool abs_leq=( hi1 != hi2 ? hi1 < hi2 : lo1 <= lo2 );
    QAQ ( s1 ? !abs_leq : abs_leq );
}
```

## T4 琪亚娜与送货

## 题目描述

一年一度的月球节到了！

“姨妈，你看，可爱吧”

琪亚娜蹦进办公室，将一个拿着苦瓜的小玩偶给德丽莎展示着。

“今年月球节大家都开始收集德丽傻玩偶了，还是我提供的主意呢！”

......

虽然被德丽莎赶出去还被犹大砸了一下，但总归是要到了“德丽傻大收集”活动的奖品资助。

但是不知道是因为姨妈的命令还是毒瘤出题人，反正派送奖品这个任务落到了琪亚娜身上。

每次多户居民组队来参与奖品(琪亚娜玩偶)的获得，具体规则如下：

城市构成了一个美丽的树形，任意两个城市之间是连通的。

每次将会有两个居民报名，而她们城市路径上的所有居民会一起参与这次的奖品获得。

每次将会给出一个限定值：$upper$，表示只有拥有德丽傻个数大于等于$upper$的才会提供一次贡献。

最后这组的居民都会获得贡献个琪亚娜玩偶作为奖品。

但是懒懒的琪亚娜一个玩偶没有送，直到活动结束才猛然想起这件事，但是她已经算不过来要怎么送玩偶了。

好在她还保留着活动的参与信息，所以她就来找你寻求帮助了。

## 输入格式

第一行包括 $1$ 个整数 $N$，表示居民的个数。

接下来一行包括 $N$ 个整数 $W_i$，表示每个居民持有的德丽傻玩偶数量。

接下来 $N-1$ 行每行包括两个整数 $u,v$，表示居民 $u$ 和居民 $v$ 之间有一条路径。

第 $N+2$ 行包括 $1$ 个整数 $Q$，表示活动参与的信息。

接下来 $Q$ 行每行一个操作，为以下两种之一

1. $1,\ x,\ y$，表示第 $x$ 个居民又获得了 $y$ 个德丽傻玩偶。

2. $2,\ u,\ v,\ upper$，表示 $u$ 和 $v$ 报名了一场限制为 $upper$ 的兑换活动。

注意：$2$ 询问读入 $upper$ 之后要和上次 $2$ 询问得到的贡献做一次异或来解密，但是 $1$ 询问不需要。

保证每个居民的德丽傻数量不会超过 $1 \times 10^5$

```cpp
cin>>u>>v>>upper;

do...
cnt=本次查询每个点需要增加的值
```

## 输出格式

输出包括 $1$ 行 $N$ 个整数表示每个居民得到的琪亚娜玩偶数量。

### 输入 #1

```
5

1 2
1 3
2 4
3 5
4
2 4 5 4
1 2 2
2 2 5 6

```

```
8 8 5 6 5
```

$1 \le N, Q \le 1 \times 10^5,1 \le W_i, X \le 1 \times 10^5, 1 \le u,v \le N$。

对于 $20\%$ 的测试点，满足性质 $1 \le N, Q \le 1 \times 10^3$。

对于 $10\%$ 的测试点，保证给出的是一条链。
